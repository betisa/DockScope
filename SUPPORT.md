# Support

Use GitHub Issues for reproducible DockScope bugs and feature requests.

Before opening a bug:

```powershell
docker version
docker context show
docker compose version
```

Include:

- DockScope version
- Windows version
- Docker Desktop / Engine version
- whether the app is NSIS-installed or Portable
- exact reproduction steps
- sanitized logs/screenshots

Do not post:

- API keys
- registry credentials
- private environment variables
- unredacted connection strings
- sensitive Diagnostics Bundles

For security vulnerabilities, follow `SECURITY.md`.
